# Linux / BMC 服务器批量巡检与资产采集

**项目背景**：该公开版本来源于本人实际工作中的 Linux 主机巡检、BMC/IPMI 信息采集和批量结果整理场景，使用模拟数据重新实现，不对应虚构客户或生产部署。

**本人负责内容**：设计只读采集范围、主机清单校验、SSH 与 FRU 信息解析、失败分类、批量隔离处理和 Excel/CSV 报告输出。

**主要问题**：多台主机巡检时，手工采集和整理耗时；一台设备连接失败会干扰批量结果，缺失字段也容易被误看作正常。

**解决方案**：固定 Linux 只读命令和 IPMI FRU 查询；默认 mock 模式可直接演示，real 模式要求已知 SSH 主机密钥、环境变量凭证和授权目标；单台或单字段失败写入失败明细并继续后续采集。

**结果**：公开模拟清单可生成含 Summary、Linux Status、BMC Inventory、Failures 的 Excel，以及 CSV、JSON 报告；自动测试覆盖正常、超时、认证失败、部分字段缺失与凭证处理。实际生产环境的联机效果未在此公开版本中验证。

**可扩展方向**：按授权环境增加只读硬件指标、报告趋势比较和告警规则，但需另行验证不同系统及 BMC 型号的输出差异。
